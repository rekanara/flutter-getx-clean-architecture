# Security Policy

## Supported Versions

Since this is a boilerplate/template, we strongly recommend always pulling the latest changes from the `main` branch before starting a new project. Security updates are applied to the latest version.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability in this boilerplate, please do **NOT** report it by creating a public GitHub issue.

Instead, please use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) to report it privately to the maintainers, or contact the repository owner directly.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact (e.g., how an attacker could exploit this in a forked app).

We will acknowledge receipt of your vulnerability report within 48 hours and strive to provide a patch or mitigation strategy quickly.
